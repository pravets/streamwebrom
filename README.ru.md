# StreamWebRom

[Español](README.md) · [English](README.en.md) · **Русский**

**Версия 1.12.0:** Продвинутый захват окон, вкладок и системы с изолированным звуком в Windows x64 — интерфейс студии при этом не меняется. Веб-выбор источника и звука с защитой от эха голосов. [Продвинутый захват](docs/ru/ADVANCED-CAPTURE.md), [звук и работа в фоне](docs/ru/AUDIO-AND-BACKGROUND.md), [приложения](mobile/README.en.md) и [изменения](CHANGELOG.md).

Код и загрузки: [GitHub](https://github.com/webr0m/streamwebrom) · [GitLab](https://gitlab.com/ridrogo/streamwebrom) · [Gitea](https://gitea.com/webrom/streamwebrom).

**Студия прямых трансляций в одном бинарнике.** Гости по ссылке, чистый выход для OBS,
мультистрим в YouTube/Twitch/Facebook/Kick, изолированная запись каждого гостя и живой брендинг.
Сервер на Go (SFU WebRTC на [pion](https://github.com/pion/webrtc)), веб-клиент без зависимостей.

Вдохновлено VDO.Ninja, StreamYard и Discord — переписано с нуля, с аудитом и тестами.
С версии 1.3 у студии **интерфейс в стиле StreamYard**: сцены слева, холст и раскладки в центре, бэкстейдж и панель кнопок снизу, панели с рейлом иконок справа.
См. [docs/en/AUDIT.md](docs/en/AUDIT.md).

## Быстрый старт

Скачайте бинарник для своей платформы в **Releases** и запустите:

```bash
# Только этот компьютер (http://localhost:8443)
./streamwebrom -open

# Телефоны и другие ПК в вашей сети (самоподписанный HTTPS, предупреждение принимается один раз)
./streamwebrom -self-signed -udp-port 50000

# Публичный сервер с сертификатом Let's Encrypt
sudo ./streamwebrom -autocert live.mydomain.com -addr :443 -udp-port 50000 -public-ip 203.0.113.10
```

**Windows:** скачайте `StreamWebRom-Windows-x64.exe` (нативное приложение .NET 8). Оно живёт в трее,
показывает ссылки и открывает студию. Для мультистрима установите ffmpeg (`winget install ffmpeg`)
или положите `ffmpeg.exe` рядом с исполняемым файлом.

**Docker:** `docker compose up -d`

**Go:** `go install github.com/webr0m/streamwebrom/cmd/streamwebrom@latest`

**Устанавливаемое веб-приложение (PWA):** откройте студию в Chrome/Edge и нажмите *Установить приложение*; работает на ПК и телефоне так же, как VDO.Ninja.

**Android:** в поставку входят тестовый APK и неподписанный APK для распространения. **iPhone/iPad:** проект SwiftUI/WKWebView и сборка для симулятора в CI; IPA для устройств требует подписи Apple. Оба клиента подключаются к вашему HTTPS-серверу. Инструкции и ограничения — в [mobile/README.en.md](mobile/README.en.md).

**Перед эфиром:** откройте `/diagnostics`, чтобы проверить браузер, камеру и микрофон, соединение с сервером, ffmpeg и настройку TURN.

### Публикация на своём домене с домашнего ПК (Cloudflare Tunnel)

Идеально, когда хостинг общий (cPanel) и не может запускать видеосерверы.

1. В Cloudflare Zero Trust создайте туннель с публичным hostname (например, `stream.example.com`) → `http://localhost:8443`.
2. В приложении для Windows отметьте *Публиковать в интернет*, введите домен и вставьте токен туннеля (хранится зашифрованным через DPAPI). Приложение скачает `cloudflared` и запустит его.
3. Пробросьте на роутере порт **UDP 50000** на свой ПК для прямых соединений. Для ограниченных мобильных сетей, CGNAT или блокировки UDP дополнительно настройте **ретранслятор TURN с TCP/TLS**, лучше всего на порту 443. Веб и сигнализация идут через Cloudflare Tunnel; HTTP-туннель не переносит аудио/видео WebRTC. Инструкции: [мобильные сети](docs/ru/MOBILE-NETWORKS.md).

В Linux/macOS: `streamwebrom -addr 127.0.0.1:8443 -public-url https://stream.mydomain.com -udp-port 50000` и `cloudflared tunnel run --token …`.

## Работа с OBS

1. Откройте студию → **Создать студию** → пригласите людей кнопкой **🔗 Пригласить**.
2. Вкладка **🧩 OBS** → скопируйте **Полная программа**.
3. OBS → Источники → **+** → **Браузер** → вставьте URL · 1920×1080 · отметьте *Управлять аудио через OBS*.

| URL | Для чего |
|---|---|
| `/view?room=R&scene=1#key=VIEWKEY` | Полная программа с раскладкой, брендингом и баннерами |
| `/view?room=R&scene=1&transparent=1#key=…` | То же с прозрачным фоном — для ваших сцен в OBS |
| `/view?room=R&stream=ID#key=…` | Один гость на весь экран (`&cover=1` обрезает, `&mute=1` без звука) |
| `POST /whip/R/obs` + Bearer `pushKey` | OBS → Настройки → Вещание → Сервис **WHIP** |
| `POST /whep/R/program` + Bearer `viewKey` | Плееры WHEP |

Ключи передаются во фрагменте `#`, который браузер не отправляет ни на сервер, ни в логи.

WHIP на зарезервированный ID `program` требует `hostKey`; для источников вроде `obs` или `cam` используйте `pushKey`. Запросы DELETE/PATCH требуют соответствующего Bearer. Отправляйте полный SDP: PATCH для trickle ICE возвращает 501, потому что он не реализован.

## Параметры URL (в стиле VDO.Ninja)

**Гость** `/guest?room=R&…`

| Параметр | Действие |
|---|---|
| `label=Ana` · `autostart` | Предзаполненное имя · вход без экрана предпросмотра |
| `password=` | Пароль комнаты |
| `videodevice=` · `audiodevice=` · `outputdevice=` | Устройство по номеру (1, 2…), части имени (`obs`, `logitech`) или `0` — без устройства |
| `quality=0/1/2` · `height=1080` · `fps=60` | Разрешение и кадры |
| `bitrate=6000` · `codec=h264/vp8/vp9/av1` | Качество отправки |
| `stereo` · `denoise=0` · `echo=0` · `autogain=0` · `gain=150` | Профессиональный звук |
| `novideo` · `noaudio` · `muted` · `videomute` | Только звук, только видео, вход без звука |
| `screenshare` | Войти, показывая экран |
| `effects=blur/bg/replace` · `blur` · `bgpreset=green` | Видеоэффект (размытие, виртуальный фон, замена) |

**Выход для OBS** `/view?room=R&…#key=VIEWKEY`

| Параметр | Действие |
|---|---|
| `scene=1` | Полная программа · `transparent=1` прозрачный фон |
| `scene=2` … `scene=8` | Дополнительные сцены, собранные в студии |
| `stream=ID` | Одна камера (у каждого источника своя кнопка **🔗 OBS**) |
| `cover=1` · `mirror=1` · `rotate=90` · `bg=000000` | Кадрирование |
| `mute=1` · `volume=50` · `audioonly=1` | Звук |
| `label=1` · `stats=1` · `status=0` | Имя, статистика, скрыть состояние |

## Настройка

Каждый параметр — флаг или переменная окружения `SWR_<ИМЯ>` (например, `-udp-port` = `SWR_UDP_PORT`).

| Флаг | По умолчанию | Описание |
|---|---|---|
| `-addr` | `:8443` | Адрес прослушивания |
| `-self-signed` | `false` | HTTPS с постоянным самоподписанным сертификатом (LAN) |
| `-autocert` | | Домен для Let's Encrypt |
| `-tls-cert` / `-tls-key` | | Свой сертификат |
| `-udp-port` | `0` | Один порт UDP для всего медиа (рекомендуется с фаерволом/Docker) |
| `-public-ip` | | Анонсируемый публичный IP (NAT 1:1, VPS) |
| `-stun` / `-turn` / `-turn-user` / `-turn-pass` | STUN от Google и Cloudflare | Серверы ICE |
| `-ffmpeg` | `ffmpeg` | Бинарник для мультистрима и сборки записей |
| `-data` | `streamwebrom-data` | Записи и сертификаты |
| `-origins` | тот же хост | Разрешённые источники WebSocket (`*` — любые) |
| `-max-rooms` / `-max-peers` | `500` / `64` | Лимиты |
| `-msg-rate` / `-msg-burst` / `-max-msg` | `30` / `60` / `256KiB` | Защита сигнализации от злоупотреблений |
| `-admin-token` | | Включает `/api/admin/stats` и `/metrics` (Prometheus) |
| `-open` | `false` | Открыть браузер при старте |

## Разработка

```bash
make run          # локальный сервер
make test         # vet + тесты + синтаксис JS
make test-race    # детектор гонок (нужен cgo)
make all          # бинарники для linux/mac/windows (amd64 и arm64)
make launcher     # приложение Windows .NET со встроенным сервером
```

В PowerShell: `./scripts/build.ps1` собирает шесть серверов, лаунчер Windows и `dist/SHA256SUMS.txt` (нужны Go и .NET SDK 8). `./scripts/build-android.ps1` собирает APK с JDK 17 и Android SDK 35. После добавления артефактов пересчитайте контрольные суммы перед публикацией.

```
cmd/streamwebrom     точка входа
internal/sfu         SFU: публикация, подписка, пересылка RTP, PLI
internal/studio      комнаты, роли, состояние продакшена, протокол сигнализации
internal/server      HTTP, WebSocket, API, WHIP/WHEP, заголовки безопасности
internal/restream    мультистрим RTMP/SRT через ffmpeg
internal/record      изолированная запись по источникам
internal/tlsutil     самоподписанные сертификаты для LAN
web/                 клиент (модули ES, без сборки): студия, гость, выход для OBS
windows/             нативный лаунчер .NET 8 для Windows
```

Тесты включают настоящую интеграцию: один клиент WebRTC публикует по WHIP, другой принимает по WHEP,
поток записывается, а затем идёт мультистрим VP8+Opus → H.264+AAC на локальный сервер RTMP.
