# Общий доступ к окнам, вкладкам и аудио (v1.12.0)

[Español](../CAPTURA-AVANZADA.md) · [English](../en/ADVANCED-CAPTURE.md) · **Русский**

Студия и элементы управления гостей сохраняют свой интерфейс. Кнопка общего доступа позволяет выбрать источник и звук. Ведущий по-прежнему разрешает гостям доступ прежде, чем они начнут делиться.

## Расширенный захват для Windows x64

Скачайте `StreamWebRom-Capture-Windows-x64.zip` из публикаций проекта. Распакуйте папку целиком и запустите `StreamWebRom-Capture.exe`. Откройте свой HTTPS-сервер или `http://localhost:puerto` и войдите в обычную комнату. Создавать другой сервер или использовать другой ретранслятор не требуется.

Лаунчер предлагает «Расширенный захват». Если установить содержимое папки из ZIP в `%LOCALAPPDATA%\StreamWebRomCapture`, эта кнопка открывает клиент с настроенным сервером; если не установлено — открывает страницу загрузок.

- **Окно:** передаёт видео окна и звук выбранного приложения. Несколько окон одной программы могут принадлежать одному процессу и делить его звук.
- **Полный экран:** передаёт монитор и системный звук, исключая дерево процессов клиента, который воспроизводит голоса комнаты.
- **Веб-вкладка:** открывает адрес содержимого внутри клиента и выбирает эту вкладку. Её звук захватывается независимо. Вкладки, уже открытые в Chrome, делятся из Chrome, либо можно открыть их адрес в клиенте.
- **Без звука:** передаётся только видео.

Используйте клиент также для прослушивания комнаты. Если вы воспроизводите звонок в другой программе, не относящейся к клиенту, это воспроизведение относится к системному звуку и не может быть исключено автоматически. Не открывайте вторую слышимую копию звонка, пока делитесь системой. Вкладки с содержимым, открытые внутри клиента, делятся через «Веб-вкладка»; системный режим исключает всё их дерево, чтобы защитить голоса.

Нативный захват использует WASAPI Process Loopback. Требуется версия Windows, поддерживающая этот API, и работающее аудиоустройство. Если Windows это не позволяет, селектор показывает ошибку и даёт выбрать другой источник или видео без звука. Этот нативный клиент распространяется для Windows x64; эквивалентный нативный захват не заявляется для Android, iOS, macOS или Linux.

## Из Chrome и других браузеров

Селектор предлагает вкладку, окно или полный экран. Браузер решает, какие источники и звук он разрешает в этой операционной системе. Для звука другой вкладки включите «Поделиться аудио» в диалоге браузера. Общий звук сохраняется только когда браузер подтверждает, что может исключить сам звонок; если изолировать его не удаётся, отправляется видео и выводится указание использовать расширенный захват. Эта проверка не позволяет вернуть голоса участников.

## Реализация и валидация

Движок Windows адаптирует компонент MIT [electron-native-screenshare](https://github.com/CilginSinek/electron-native-screenshare), закреплённый за коммитом, указанным в `desktop/vendor/native-audio/ORIGIN.md`. Лицензия и происхождение поставляются вместе с ZIP. Захват использует вспомогательный процесс с тайм-аутом запуска и ограниченными буферами; сбой устройства останавливает этот источник, не перезапуская комнату. Сайт не получает ни API Node, ни свободный доступ к процессам.

Физические проверки в Windows используют сгенерированные тоны, чтобы различить звонок, внешнее приложение и вкладку. Они проверяют включение по приложению, исключение дерева Chromium, воспроизводящего звонок, звук вкладки и передачу PCM через вспомогательный процесс. Записи не сохраняются. CI проверяет реальный селектор, публикацию видео, изоляцию содержимого и упакованный клиент. Эти проверки не сертифицируют все доступные драйверы или устройства.

## Сборка и публикация

`npm ci --ignore-scripts`, `node node_modules/electron/install.js`, `npm run native:build`, `npm test` и `npm run package:windows` — внутри `desktop`, с Node 24 и инструментами C++/SDK для Windows. Версии закреплены в lockfile. Артефакты сервера, мобильных приложений и клиента публикуются вместе после прохождения их проверок и расчёта `SHA256SUMS.txt`. Задания по тегам не перезаписывают опубликованные файлы.
